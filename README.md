# weblayout-skillbox-module7-practce

Практическая работа по адаптивной верстке с использованием sass

## Задача

Выполнить адаптивную верстку страницы, добавить 2x изображения.

## Этапы выполнения

### Первый этап

Скачаны изображения в разрешении 2x и добавлены в верстку.

### Второй этап

- Адаптация хедера под разрешение 768px.
- Адаптация футера под разрешение 768px.
- Адаптация хедера под разрешение 375px.
- Адаптация футера под разрешение 375px.

### Третий этап

- Адаптация секции *hero* под разрешение 768px.
- Адаптация секции *hero* под разрешение 375px.

### Четвертый этап

- Адаптация секции *about company* под разрешение 768px
- Адаптация секции *about company* под разрешение 375px
